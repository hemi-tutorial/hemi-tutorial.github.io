# HEMI Tutorial Website

A dependency-free static website for the **Tutorial on Human-centric Embodied Multimodal Interaction (HEMI)** in conjunction with ICMI 2026.

## Pages

- `index.html` - homepage and tutorial overview
- `about.html` - theme, topics, and ICMI relevance
- `learning-objectives.html` - learning outcomes and target audience
- `agenda.html` - tentative half-day schedule
- `organizers.html` - organizer biographies and selected publications
- `materials.html` - supporting material hub

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Open **Settings > Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the branch containing the site and the `/ (root)` folder, then save.

No build step or external dependencies are required.
